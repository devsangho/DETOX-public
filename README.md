# DETOX

**DETOX: Runtime Defense for Vision–Language–Action Models under Attack**

Static project page. GitHub Pages serves it from the root of `main`.

- `index.html`: the page
- `static/detox.css`: styles (Solar Dawn design system)
- `static/detox.js`: motion graphics and animated charts
- `static/data/ur5e_traces.js`: recorded 50 Hz gripper aperture of two triggered UR5e trials
- `static/img/`: method figure and the UR5e setup photo

The paper is under double-blind review. Author names, the preprint link, and code will be added after the review period.
Until then the page carries `noindex` and `robots.txt` disallows crawling.
